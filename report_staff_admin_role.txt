========================================================================

RESTAURANT POINT OF SALE (POS) SYSTEM - GROUP 2 (GEN 6)

Module: Menu and Table Management (Ra Daro)

Document: Current System Capabilities for Staff & Admin

========================================================================

1. STAFF MODE (ប្រតិបត្តិការប្រចាំថ្ងៃសម្រាប់បុគ្គលិក)

------------------------------------------------------------------------

ក្នុងដំណាក់កាលបច្ចុប្បន្ន បុគ្គលិក (Staff) អាចអនុវត្តការងារសំខាន់ៗដូចខាងក្រោម៖

* ពិនិត្យបញ្ជីមុខម្ហូប និងភេសជ្ជៈ (View Menu):

  - មើលបញ្ជីមុខម្ហូប (Food) និងភេសជ្ជៈ (Drink) ទាំងអស់ រួមទាំងលេខកូដ (Item ID) តម្លៃ និងស្ថានភាពស្តុក (Available ឬ Out of Stock)។
* ពិនិត្យស្ថានភាពតុក្នុងហាង (View Tables):

  - មើលលេខតុ ចំនួនកៅអី និងស្ថានភាពបច្ចុប្បន្នរបស់តុនីមួយៗ (Available ឬ Occupied ជាមួយលេខកូដ Order ដែលកំពុងប្រើប្រាស់)។
* បង្កើតការកម្ម៉ង់ថ្មី (Create Order - Dine-In & Takeaway):

  - Dine-In (ញ៉ាំក្នុងហាង): បុគ្គលិកអាចជ្រើសរើសលេខតុទំនេរឱ្យភ្ញៀវ។ ប្រព័ន្ធនឹងប្តូរស្ថានភាពតុនោះទៅជា "Occupied" ដោយស្វ័យប្រវត្តិ និងការពារមិនឱ្យដាក់ Order ទីពីរជាន់លើតុដែលកំពុងមានភ្ញៀវអង្គុយឡើយ។

  - Takeaway (ខ្ចប់យកទៅក្រៅ): បុគ្គលិកអាចបង្កើតការកម្ម៉ង់ដោយមិនចាំបាច់រើសលេខតុ (Bypass Table) ដើម្បីរក្សាតុទំនេរទុកឱ្យភ្ញៀវមកអង្គុយក្នុងហាង។

  - ការជ្រើសរើសមុខម្ហូប និងគណនាតម្លៃ: បុគ្គលិកវាយបញ្ចូល Item ID និងចំនួន (Quantity)។ ប្រព័ន្ធនឹងផ្ទៀងផ្ទាត់ភ្លាមៗថា Item ID ត្រឹមត្រូវ និងមានក្នុងស្តុកឬអត់ (បើខុស ឬអស់ស្តុក ប្រព័ន្ធនឹងជូនដំណឹងភ្លាមដោយមិនចាំបាច់វាយចំនួនឡើយ) រួចបង្ហាញតម្លៃរាយ និងតម្លៃសរុបរបស់មុខម្ហូបនីមួយៗ។
* បញ្ចប់ការកម្ម៉ង់ និងបើកតុឱ្យទំនេរវិញ (Complete Order & Release Table):

  - នៅពេលភ្ញៀវញ៉ាំរួចរាល់ និងទូទាត់ប្រាក់ហើយ បុគ្គលិកអាចបញ្ចប់ Order តាមលេខតុ ដើម្បីដោះសោរតុនោះឱ្យត្រឡប់មកស្ថានភាព "Available" សម្រាប់ទទួលភ្ញៀវបន្ទាប់។


2. ADMIN MODE (ការគ្រប់គ្រងមុខម្ហូបសម្រាប់អ្នកគ្រប់គ្រង)

------------------------------------------------------------------------

ក្នុងដំណាក់កាលបច្ចុប្បន្ន អ្នកគ្រប់គ្រង (Admin) មានសិទ្ធិគ្រប់គ្រងទិន្នន័យមុខម្ហូបដូចខាងក្រោម៖
* មើលបញ្ជីមុខម្ហូបទាំងអស់ (View Full Menu):

  - ពិនិត្យមើលទិន្នន័យមុខម្ហូប និងភេសជ្ជៈទាំងអស់ដែលមានក្នុងប្រព័ន្ធ។
* បន្ថែមមុខម្ហូប ឬភេសជ្ជៈថ្មី (Add New Menu Item):

  - បង្កើតមុខម្ហូបថ្មី (Food - អាចកំណត់ថាហឹរ ឬមិនហឹរ) ឬភេសជ្ជៈថ្មី (Drink - អាចកំណត់ទំហំ Small, Regular, Large) ដោយកំណត់ Item ID ឈ្មោះ និងតម្លៃ។ ប្រព័ន្ធនឹងការពារមិនឱ្យបង្កើត Item ID ជាន់គ្នាឡើយ។
* កែប្រែឈ្មោះ និងតម្លៃមុខម្ហូប (Edit Item Name / Price):

  - កែសម្រួលឈ្មោះ ឬផ្លាស់ប្តូរតម្លៃរបស់មុខម្ហូបដែលមានស្រាប់។ រាល់ការកែប្រែទាំងអស់នឹងត្រូវបានរក្សាទុកក្នុងឯកសារ JSON និងមានប្រសិទ្ធភាពភ្លាមៗសម្រាប់ Order ថ្មីៗរបស់ Staff។
* បិទ ឬបើកដំណើរការមុខម្ហូបបណ្តោះអាសន្ន (Activate / Deactivate Menu Item):

  - កំណត់ស្ថានភាពមុខម្ហូបណាមួយថាអស់ស្តុក (Inactive / Out of Stock) ដោយមិនចាំបាច់លុបទិន្នន័យចោល ដើម្បីកុំឱ្យ Staff ច្រឡំកម្ម៉ង់ឱ្យភ្ញៀវ ហើយអាចបើកដំណើរការវិញបានគ្រប់ពេល។

* លុបមុខម្ហូបចេញពីប្រព័ន្ធជាអចិន្ត្រៃយ៍ (Permanently Remove Menu Item):

  - លុបមុខម្ហូបដែលឈប់លក់ចេញពីបញ្ជី និងឯកសាររក្សាទុកទិន្នន័យ (menu_data.json) ទាំងស្រុង។

3. លក្ខណៈពិសេសនៃការរក្សាទុកទិន្នន័យ (Data Persistence)

------------------------------------------------------------------------

* រាល់ការផ្លាស់ប្តូរដែលធ្វើឡើងដោយ Staff (ដូចជាការកក់តុ ឬបញ្ចប់តុ) និង Admin (ដូចជាការបន្ថែម កែតម្លៃ ឬបិទមុខម្ហូប) ត្រូវបានរក្សាទុកដោយស្វ័យប្រវត្តិទៅក្នុងឯកសារ `data/menu_data.json` និង `data/table_data.json` ដូច្នេះទិន្នន័យនឹងមិនបាត់បង់ឡើយទោះបីជាបិទកម្មវិធី POS ហើយបើកឡើងវិញក៏ដោយ។
